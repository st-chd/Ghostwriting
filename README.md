# Ghostwriting

초안을 맥락과 페르소나에 맞는 3인칭 글로 확장하는 SillyTavern용 확장프로그램입니다.

## 크레딧
이 확장프로그램은 [GuidedGenerations-Extension](https://github.com/Samueras/GuidedGenerations-Extension/)의 `Impersonation` 기능에서 아이디어를 얻었으며, 원래 소스코드를 복사하거나 참고하지 않고 Codex(GPT)를 활용해 기능 요구사항만으로 처음부터 구현한 프로젝트입니다.

## 설치

SillyTavern의 확장 프로그램 설치 메뉴에서 다음 저장소 URL을 사용하세요.

```txt
https://github.com/st-chd/Ghostwriting
```

설치가 끝나면 SillyTavern을 새로고침합니다.

## 사용

1. **확장** 패널의 **Ghostwriting**을 열고 **Ghostwriting 사용**에 체크합니다.
2. **변환용 연결 프로필**에서 **메인 API 사용**을 선택하면 현재 SillyTavern에서 선택한 API·모델·생성 설정으로 작성합니다. 별도 모델을 쓰려면 연결 관리자에 저장된 프로필을 선택합니다.
3. 상단바 - **확장** 메뉴에서는 연결 프로필, 출력 언어, 공통 프롬프트, 프롬프트 프리셋을 설정합니다. 프리셋은 모든 페르소나에서 공유됩니다. 출력 언어는 영어가 기본값이며 한국어로 바꿀 수 있습니다.
4. 입력창 옆 **마법봉** 메뉴의 **Ghostwriting 설정**에서 묘사 범위, 분량, 최근 메시지 수, 페르소나별 추가 지시사항을 설정합니다.
5. 입력창에 한글 원문을 적고 전송 버튼 왼쪽의 깃펜을 누릅니다. 선택한 언어의 결과는 입력창에만 들어가며 자동 전송되지 않습니다.
6. 첫 결과를 받은 뒤 깃펜을 누르면 결과 패널을 먼저 엽니다. 한 번에 한 결과를 보여주며, 좌우 화살표나 가로 스와이프로 다른 결과를 확인하고 **입력창에 적용**으로 선택합니다. 패널이 열린 상태에서 깃펜을 한 번 더 누르면 원문을 기준으로 재작성합니다. 결과 칸은 `재작성 · 1`, `재작성 · 2`, `재작성 · 3`이며, 네 번째 작성부터 기존 칸을 덮어씁니다. 현재 선택하여 수정 중인 칸은 덮어쓰지 않으며, 다음에 덮어쓸 칸은 패널에 표시됩니다.
7. 되돌리기 버튼은 결과 기록을 남기고 원문을 되살립니다. 결과 패널의 **비우기(휴지통)**는 결과 기록을 모두 지우고 입력창을 원문으로 복원합니다. 이후 작성은 `재작성 · 1`부터 시작합니다.

## 참고사항

#### 참고 자료와 제한

- 현재 페르소나 시트와 캐릭터 시트는 항상 참고합니다. 1:1 채팅만 지원합니다.
- 연결 프로필에 지정된 생성 설정(온도, 응답 길이 등)을 사용합니다. 프리셋 내용은 전송되지 않습니다.
- 최근 메시지 수는 사용자와 캐릭터 메시지를 합친 개수이며, 기본값은 10개, 최대 200개입니다.
- 선택된 최근 대화의 본문 합계가 120,000자를 넘으면 요청을 보내지 않고 메시지 수를 줄이라는 안내를 표시합니다.
- 이 제한은 토큰 수나 모델의 문맥 한도를 보장하지 않습니다. 매우 긴 시트나 문맥 한도가 작은 모델에서는 요청이 거절될 수 있습니다.


#### 입력창과 결과 기록

- 입력창을 완전히 비우거나 전체 내용을 새로 바꾸면 이전 원문과 결과 기록이 초기화되고, 이후 작성한 내용이 새 원문이 됩니다.
- 일부만 고치면 현재 결과의 수정으로 유지됩니다.
- 작성 중 버튼을 다시 누르거나, 입력창, Ghostwriting 버튼에 초점이 있을 때 Escape를 누르면 취소하며, 늦게 도착한 결과는 입력창에 적용하지 않습니다.

#### 응답 길이

- **메인 API**: 현재 사용중인 API설정의 응답 길이를 따릅니다.
- **연결 프로필**: 해당 프로필의 생성 프리셋을 따르며, 유효한 값이 없으면 4,096토큰을 사용합니다.


#### 저장과 삭제

- 원문과 결과 버전은 새로고침 후 복원을 위해 브라우저 localStorage에 암호화 없이 저장됩니다. 메시지로 전송하거나 확장의 데이터 정리를 실행하면 삭제되며, 전송하지 않은 초안은 브라우저에 남습니다.
- 공통 프롬프트 프리셋과 페르소나별 추가 지시사항은 사용자 `settings.json`에 저장됩니다.
- 확장을 제거하면 위 설정과 현재 브라우저의 초안이 함께 삭제됩니다.
